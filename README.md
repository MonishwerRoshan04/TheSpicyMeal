# 🍕 The Spicy Meal - Modern Restaurant & Food Ordering Landing Page

A rich, responsive restaurant and dining experience web application designed to showcase signature dishes, interactive table reservations, live promotional offers, and culinary stories.

## 🌐 Live Demo
- **Netlify Live URL:** [View Live Website](https://thespicy-meal.netlify.app/)

## ✨ Key Features
- **Live Special Combo Countdown Timer:** Real-time JavaScript countdown (`Day`, `Hour`, `Minute`, `Second`) creating urgency for limited-time discount offers.
- **Interactive Table Reservation System:** Complete booking form with client-side validation for name, email, phone number, reservation date, and guest count.
- **Category & Menu Exploration:** Organized food categories (*Delish Burger*, *Sandwiches*, *Mexican Cuisine*, *Italian Cuisine*) alongside a detailed pricing menu with dish descriptions.
- **Dynamic Guest Testimonial Slider:** Interactive customer review carousel featuring verified ratings and smooth navigation controls.
- **Culinary Team & Food Blog:** Dedicated sections highlighting executive chefs and latest recipe/culinary blog posts.
- **Fully Responsive Design:** Crafted with a bold dark-and-crimson color palette optimized for seamless viewing across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for menus, forms, and content sections.
- **CSS3:** Custom styling, dark-mode textures, Flexbox, and CSS Grid layouts.
- **Bootstrap 5:** Responsive grid system, navigation bar, and UI components.
- **Vanilla JavaScript (ES6+):** Live countdown timer logic, interactive form validation, cart/booking triggers, and testimonial slider controls.
- **AOS (Animate On Scroll):** Smooth scroll-triggered reveal animations.
